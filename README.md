## 一、游戏背景

元末至正年间，朝政腐败，旱蝗交加，黄河决口，疫病肆虐，天下苍生民不聊生。  
至正四年（1344年），濠州钟离贫农朱重八家破人亡，走投无路之下入皇觉寺为沙弥，后因饥荒托钵云游淮西三年，尝尽人间冷暖。  
至正十二年（1352年），收到同乡汤和手书，毅然投奔郭子兴红巾义军，自此踏上一统江山、驱逐胡虏的开国帝王霸业！

## 二、核心特色

- **正统明史叙事**：忠实取材于《明史·太祖本纪》、《明太祖实录》与高岱《鸿猷录》，真实再现横涧山夜袭、采石矶渡江、三顾刘伯温、洪都八十五日坚守与鄱阳湖火攻等经典战役。
- **帝王心术双轨抉择**：
  - **【仁厚】**：体恤生民、善待功臣、轻徭薄赋，走民贵君轻的儒家王道圣君之路。
  - **【铁血】**：军令如山、重典肃贪、霹雳手段，走威震万邦、集权极峰的开国霸皇之路。
  - 玩家在历史事件中的每一个决定，都会重塑朱元璋的性格走向，并决定结局评价与谥号。
- **名将谋臣深度协同**：徐达、常遇春、刘伯温、李善长、马皇后悉数登场，每位历史名臣具备独特的战斗定位与怒气绝技。
- **全动态战术战斗**：包含集火指令、怒气积攒大招、战场急救（金创药）与火器轰击（神机营震天雷）。
- **国风古韵与独立音效**：使用 Web Audio API 原生合成古朴战鼓、鸣金、拔刀挥击与胜利凯歌，无需加载外部繁重音频包。
- **随时存档与离线游玩**：支持浏览器 LocalStorage 即时自动保存与手动奉旨存录，征途永不遗失。

## 三、玩法系统详解

### 1. 历史本纪（主线剧情与抉择）
- 呈现历史叙事文本与核心情境冲突。
- 每一个事件提供 2 至 3 项重大抉择：
  - 会影响 **粮草、白银、兵力、士气民望** 的增减；
  - 会调整 **【仁德】与【铁血】** 的数值平衡；
  - 可能会直接引出重要历史人物归附（如郭子兴义女马秀英、大将常遇春、谋臣刘伯温等）；
  - 亦可直接点燃重大战役交锋。

### 2. 战法交锋（小队回合制战役）
- **阵营布局**：我方出战名将（朱元璋、徐达、常遇春、刘伯温、李善长、马皇后等）迎战敌方精锐（元廷官军、元将也先帖木儿、张士诚水军、陈友谅汉军水师等）。
- **操作指令**：
  - **普攻**：攻击指定敌方单位，造成物理伤害并回复 18 点怒气。
  - **怒气绝技**（满 100 怒气时解锁）：
    - **朱元璋·日月同辉**：以帝王霸气猛击敌酋并为全军恢复 80 点生命。
    - **徐达·固若金汤**：开国第一名将盾防，为全军施加高额伤害吸收护盾。
    - **常遇春·虎贲陷阵**：十万先锋强袭，造成毁灭性单体伤害并必定附加重创。
    - **刘伯温·天道奇门**：呼风唤雨引天雷借法，对敌全军造成群体道术伤害并概率震慑眩晕。
    - **李善长·漕运筹饷**：粮饷精调，恢复全军生命并为全员补充 30 怒气。
    - **马皇后·布衣圣母**：至仁救赎，超量急救我方濒危将士。
  - **集火指令**：点击敌方阵列中的任意将领头像，即可将集火标靶锁定在该目标身上，集中火力优先斩首敌方主帅或脆皮军师。
  - **战地军需道具**：
    - **金创灵药**：紧急救治生命值百分比最低的一位名将（回血 180 点）。
    - **神机营震天雷**：掷出大明初创火器，造成全体无视护甲的爆裂火伤。

### 3. 军政经略（内政与军务沙盘）
主线剧情推进间隙，玩家可随时进入【军政府】实施经略，壮大根据地：
- **政令颁布**：
  - **军屯大计**：寓兵于农，消耗白银换取连绵粮仓，提升屯粮产出；
  - **开仓赈济**：以粮抚民，安抚流民，大幅提升民心与三军士气；
  - **严饬军纪**：重典治军，禁掠民物，提升大军威慑与铁血心术；
  - **招贤纳士**：颁招贤榜延揽江南儒士名流，广纳奇才；
  - **整军备武**：拨发安家饷银，募召江淮健儿扩充虎贲战卒；
  - **造火铳大炮**：调集工匠开炉铸造明军早期火铳与回回火炮。
- **全军营盘犒赏**：消耗 30 担军粮开锅杀羊，一键恢复全军名臣武将的气血。
- **辎重军械市集**：在后勤集市平抑物价，补充金创药、神机营震天雷等重要军需储备。

### 4. 名臣列传（武将谋士谱系）
- 查看已归顺与待招揽的淮西二十四将及江南名士。
- 每位名将记载有正史生卒年、官职与生平列传（如魏国公徐达、开平王常遇春、诚意伯刘伯温等）。
- **名将擢升**：消耗白银与粮饷，为功臣晋爵加俸，永久提升攻击力、护甲与最大生命值上限。

## 四、资源与数值规则

| 资源项 | 作用 | 获取/消耗途径 |
| :--- | :--- | :--- |
| **军粮 (担)** | 军队补给与全军疗伤基石 | 屯田积粮、大战缴获；犒赏三军、招募行军消耗 |
| **白银 (两)** | 延揽人才、军需采购与武将封赏 | 商税征收、平叛战利品；购买火器、名将晋阶消耗 |
| **精兵 (百人)** | 明军主力建制规模 | 招募义勇、投诚降兵收编；征战折损 |
| **士气/民望 (%)** | 军队作战攻击力修正与剧情判定 | 胜仗凯旋、赈济灾民提升；败绩或掠民行为扣减 |
| **仁德 / 铁血** | 朱元璋双向心术性格 | 剧情抉择与军纪政令决定，影响最终帝王谥号与史家评述 |

## 五、历史五卷章节速览

1. **第一卷·皇觉寒芒 (1344–1352)**  
   *淮西大旱、托钵为僧、行乞游历、同乡来信。*
2. **第二卷·红巾烽火 (1352–1355)**  
   *濠州投军、义娶马氏、淮西结义、横涧山整编精锐。*
3. **第三卷·金陵定鼎 (1356–1360)**  
   *强渡采石、定鼎集庆、征召刘基、高筑墙广积粮缓称王。*
4. **第四卷·鄱阳烈焰 (1363)**  
   *洪都苦守、水师援赣、康郎山激战、东北风借势火烧汉王巨舰。*
5. **第五卷·日月重开 (1367–1368+)**  
   *平定张士诚、发布北伐中原檄、徐达攻克元大都、应天南郊即皇帝位。*

## 六、终章与帝王谥号系统

当完成北伐大业定鼎南京后，史官将根据全剧积累的 **【仁德】** 与 **【铁血】** 值，进行御笔定谥并出具史官总论：
- **大明太祖 · 仁厚布衣圣君**（仁德显著领先）：  
  *轻徭薄赋，与民休息。保护元勋功臣，善待天下黎庶，史称“洪武仁治”。*
- **大明太祖 · 震古烁今铁血霸皇**（铁血显著领先）：  
  *严刑峻法，重典肃贪。设锦衣亲军，扫荡残元，威震万邦。*
- **大明太祖 · 兼济刚柔一代雄主**（仁德与铁血并重）：  
  *仁以安民，法以惩贪。文武兼济，日月重开，开创近三百年之极盛大明！*

通关后，玩家可选择重新从皇觉寺开启轮回再起义旗，或停留在洪武盛世继续在自由沙盘模式下治世摄政。
